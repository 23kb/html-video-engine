      • Customizing Search

          Manage the overall design and functionality from the shop search page.
        • Enable AJAX On Search Fields
            Allow your customers to search and get results in real time without loading other pages.
          • Enable search by SKU
              Return search results based on either product name or SKU.
            • Results Amount per Search

                Control the maximum amount of products to show in the search results.

                • Save/publish the changes is required to see this option working in the customizer preview.
                • Results Description Length

                    The number of words to show in the results description. Save/publish the changes is required to see this option working in the customizer preview.

                      • Display Categories

                        • Display Tags
                            Display product tags in the results if the searched term matches with tag name.
                          • Display Attributes
                              Display selected product attributes in the results if the searched term matches with attribute terms.
                              • Comma-separated attribute taxonomy names to include in suggestions (e.g. pa_author, pa_language, pa_format).
