Settings

Display

Number of events to include in any theme-side calendar. Default 30. Use 0 for no limit.

Select the first day of the week.

Looks Like: September 19, 2026

Looks Like: 5:06 pm

The theme-side Calendar Color styling strategy.
None by default (no colors).
Each uses a single color for each Event link.
First uses the first color found for the background.
Blend will use the average of all colors for the background.

Adjust the frontend display of event single page.

Editing

The interface to use when adding or editing Events.

Allow developers to extend post types that support events.

When adding a new Event, this Calendar will be preselected.

Time Zone

Off by default (Existing time zone data still appears).
Single allows Events to have one time zone.
Multi allows Events to have different start & end time zones.
Single and Multi will enable time zones for Calendars.
