WordPress Abilities API + Sugar Calendar

Use Sugar Calendar With Your Favorite AI

Connect your WordPress site and Sugar Calendar to AI assistants like Claude, ChatGPT, Cursor, and more. Ask about your events, calendars, and stats in plain language, and have it draft new events for you. Learn more about Abilities API

Setup AI MCP

Connecting AI MCP will install and activate our free sister plugin WPVibe.ai

Everything Sugar Calendar Can Do With AI

Events

  • Filter events by status, calendar, and date
  • Search your events by keyword
  • Create and edit events, always as drafts

Calendars

  • List all your calendars
  • Look up a calendar by id or slug
  • Create a calendar and assign events

Tags

  • List and search your event tags
  • Look up a tag by id or slug
  • Create a tag and apply it to events

Event Stats

  • Stats by date range, calendar, and month
  • Get a single event's full details

Registrations

  • Signup and revenue totals by date range
  • Compare a period against the one before
  • Counts ticket orders and going RSVPs

Tickets

  • See who's registered for an event
  • Check ticket sales and availability

Venues

  • List and look up your venues
  • Add a venue and attach it to an event

Speakers

  • List and look up your speakers
  • Add a speaker and attach them to an event

RSVP

  • See who's RSVP'd and check capacity

...And many more abilities coming soon!
